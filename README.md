# predictive.factory — Template de Documentação Off-line (Quarto)

Estrutura limpa e autônoma baseada no layout de site Quarto com tema duplo (`cosmo` / `cyborg`), modo leitura (`reader-mode`), busca local e widgets interativos 100% off-line em `widgets/`.

## Renderização Local

```bash
quarto render
```

O site estático resultante em `_site/` não possui dependências externas de CDN e pode ser aberto diretamente em ambiente isolado.
